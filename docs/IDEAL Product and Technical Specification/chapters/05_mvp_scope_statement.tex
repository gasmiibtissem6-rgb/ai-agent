\chapter{MVP Scope Statement}
\section{Included}
The MVP includes Flutter foundation, authentication flow, user profile, deal creation, deal list, deal details, party invitation, party viewing, initial deal version creation, submission, approval, rejection, change requests, version locking, post-approval new versions, basic notifications, private file attachment support, audit logging, and basic admin review.
\section{Excluded}
Advanced AI drafting, legal template marketplaces, advanced analytics, public marketplaces, complex organization billing, advanced dispute resolution, and final production KYC integration are excluded.
\section{Definition of Done}
The MVP is done when core user journeys work through the NestJS API, protected state cannot be bypassed from clients, and QA scenarios for locking, authorization, files, subscriptions, and audit logs pass.
