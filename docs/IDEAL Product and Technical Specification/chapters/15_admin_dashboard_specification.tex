\chapter{Admin Dashboard Specification}
The Next.js admin dashboard is responsible for user management, KYC review, deal activity monitoring, report handling, subscription visibility, trust event inspection, audit log review, admin user management, and platform configuration.
\importantnote{The admin dashboard must call NestJS APIs. It must not bypass backend authorization by directly writing to the database.}

\section{KYC Review Workflow}
An admin opens the KYC queue, filters submitted records, reviews private signed document previews issued by the backend, records an approval or rejection reason, and the backend writes an audit event plus a user notification. The dashboard must show loading, empty, error, permission denied, and stale-review states.
