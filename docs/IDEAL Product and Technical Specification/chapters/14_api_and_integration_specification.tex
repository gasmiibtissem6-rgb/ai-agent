\section{Request and Response Examples}
\begin{lstlisting}
POST /api/v1/deals
{
  "title": "Office renovation agreement",
  "description": "Milestone-based renovation work",
  "currency": "TND"
}

201 Created
{
  "data": {
    "id": "uuid",
    "status": "draft",
    "currentVersionId": null
  }
}
\end{lstlisting}

\begin{lstlisting}
POST /api/v1/deal-versions/{versionId}/approve
{
  "decision": "approved"
}

200 OK
{
  "data": {
    "versionId": "uuid",
    "approvalStatus": "approved",
    "dealStatus": "locked"
  }
}
\end{lstlisting}

Pagination uses \texttt{limit}, \texttt{cursor}, and \texttt{sort}. Filtering uses explicit fields such as \texttt{status}, \texttt{createdAfter}, and \texttt{participantId}. Validation errors return \texttt{VALIDATION\_ERROR}; authorization errors return \texttt{FORBIDDEN}; stale version approvals return \texttt{VERSION\_CONFLICT}.
