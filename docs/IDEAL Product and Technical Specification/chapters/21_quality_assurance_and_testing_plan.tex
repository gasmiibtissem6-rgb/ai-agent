\chapter{Quality Assurance and Testing Plan}
Testing includes unit tests, integration tests, API tests, database tests, security tests, RLS tests where direct Supabase access exists, E2E tests, manual QA, acceptance testing, and regression testing.
\section{Required Scenarios}
Registration, login, password reset, deal creation, party invitation, approval, rejection, locked version immutability, unauthorized access denial, file access denial to non-participants, subscription limit enforcement, and admin action audit.
