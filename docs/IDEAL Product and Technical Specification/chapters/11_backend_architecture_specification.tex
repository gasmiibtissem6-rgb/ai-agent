\section{Patterns}
Controllers expose HTTP endpoints. Services contain business logic. Repositories or Prisma handle persistence. DTOs validate input. Guards enforce authentication, RBAC, and resource access. Filters standardize errors. Interceptors handle response and logging concerns.
\importantnote{Use Prisma ORM with Supabase PostgreSQL unless another ORM decision is introduced and documented before implementation.}
