\section{Deployment Environments}
Local development uses developer Supabase and local NestJS/Next.js servers. Staging uses isolated Supabase, backend, admin, and Stripe test credentials. Production requires protected branches, approved migrations, monitored backend deployment, signed mobile builds, and rollback plans for API and database releases.
