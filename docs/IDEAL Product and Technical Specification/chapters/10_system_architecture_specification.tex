\chapter{System Architecture Specification}
\section{Layer Responsibilities}
\begin{itemize}
  \item Flutter owns mobile presentation and local UI state.
  \item Next.js owns internal admin presentation.
  \item NestJS owns business workflows, authorization, integrations, and audit triggers.
  \item Supabase PostgreSQL owns persistence.
  \item Supabase Auth owns authentication session lifecycle.
  \item Supabase Storage owns private file bytes.
  \item Stripe owns payment checkout and subscription events.
\end{itemize}
\decisionnote{Backend owns business logic; frontend owns presentation; database owns persistence; storage is private by default; all sensitive actions are audited.}
