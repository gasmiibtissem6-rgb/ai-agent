\chapter{Test Scenarios}
\begin{enumerate}
  \item User registration creates profile readiness state.
  \item Login returns a usable session.
  \item Deal creator invites a party.
  \item Party approves the submitted version.
  \item Rejection records reason and audit event.
  \item Locked version cannot be edited.
  \item Non-participant cannot access deal.
  \item Non-participant cannot download private file.
  \item Subscription limit blocks excess deal creation.
  \item Admin action is audited.
\end{enumerate}
