\section{Column-Level Implementation Notes}
All application tables use UUID primary keys, \texttt{created\_at}, \texttt{updated\_at} where mutable, and explicit enum columns for workflow state. Historical workflow records such as approvals, audit logs, locked versions, and admin actions must not be hard-deleted. Mutable aggregates such as deals and profiles may use soft deletion or archive timestamps when product policy requires hiding records from active views.
