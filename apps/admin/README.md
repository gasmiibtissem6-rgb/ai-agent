# IDEAL Admin Dashboard

Next.js admin dashboard for IDEAL.

The dashboard is used for internal management, moderation, user review, deal review, system monitoring, and operational control.

## Development

```bash
npm install
npm run dev
```

From the repository root, use:

```bash
npm run dev:admin
npm run build:admin
```

Open the dashboard at:

```txt
http://localhost:3000
```

## Validation

```bash
npm run build
```

From the repository root:

```bash
npm run build:admin
```
